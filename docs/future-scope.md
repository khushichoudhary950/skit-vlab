# Future Scope (not part of MVP)

These were deliberately cut from Level 1 MVP to keep it buildable by 1–2 students:

- Admin panel (manage users/departments centrally)
- Real SKIT ERP integration (currently: mock/seeded auth only)
- Online code execution / sandboxed containers
- Analytics dashboards
- Notifications system
- Certificates / progress reports
- AI learning assistant
- Multi-lab, multi-semester support
- Docker + CI/CD pipeline

These remain part of the long-term vision (see master project doc) and can be
added incrementally once the MVP is stable and demoed.
