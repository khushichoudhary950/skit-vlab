## Full Official Experiment List (12)
1. Static web pages for an online bookstore (Home w/ frames, Login, Catalogue table, Registration)
2. JavaScript form validation for Registration page (name, password, email, mobile, address)
3. XML file for Book Information + DTD validation, styled with XSL/CSS
4. Install Tomcat web server (port 8080), deploy static pages from experiments 1–2
5. JavaScript popup boxes/functions (date display, factorial, multiplication table, running sum)
6. HTML selection box (5 countries → capital), styled with CSS
7. HTML + JS: number-to-words converter (0–999) with input validation
8. Node.js server (no Express) serving static HTML/CSS files
9. Node.js + Express server: form data → JSON file → display via Handlebars
10. Node.js + Express + MongoDB: CRUD for student details via HTML form
11. Node.js + Express + MySQL: CRUD for event details via HTML form
12. Signup/Login with cookie-based auth, Node.js + Express + (MongoDB or MySQL)

## MVP Selection (5 of 12, for SKIT VLab Level 1)
Chosen to give students a natural progression from static → dynamic → full-stack,
and to map cleanly onto SKIT VLab's own experiment structure (theory → steps → task → submit):

1. **Experiment 1** — Static bookstore web pages (HTML/CSS fundamentals)
2. **Experiment 2** — JavaScript form validation (client-side logic)
3. **Experiment 8** — Node.js server without Express (raw HTTP server concepts)
4. **Experiment 10** — Express + MongoDB CRUD (full-stack data flow — directly reusable pattern for SKIT VLab's own backend)
5. **Experiment 12** — Signup/Login with cookie auth (security fundamentals)

Experiments 3–7, 9, 11 are deferred — can be added in Level 2 without restructuring the schema.
